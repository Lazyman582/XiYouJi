# Disco Dialogue Prototype

Original, data-driven top-down narrative RPG prototype.

- WASD: walk
- Left mouse: click-to-move
- E: interact
- Space / Enter: reveal or advance
- 1-9: choose dialogue
- Esc: close dialogue

Dialogue is stored in a `DialogueGraph` ScriptableObject. Add nodes and choices in the inspector, then assign the graph to a `PrototypeInteractable`.
