# 白骨精 / 唐僧：点击移动、动画与相机跟随

## 使用

1. 在已有可行走 NavMesh 的地图中，停用原来的 `Player_ClickMove`（孙悟空）对象。
2. 从本目录拖入 `BaiGuJing_ClickMove.prefab`（白骨精）或 `TangSeng_ClickMove.prefab`（唐僧），放到可行走地面上。
3. 保持地图主相机的标签为 `MainCamera`，然后进入 Play 模式。鼠标左键点击地面，角色会寻路移动并转向。
4. 相机会自动跟随当前角色，沿用地图原有的跟随角度和移动边界。走动时循环播放走路动画，停止后平滑回到呼吸待机。

同一时间只启用一个可操控角色。两个新角色和孙悟空都监听左键，不包含队伍选择或多人同时操控系统。切换时先停用旧角色，再启用新角色。

这两个预制体是新增资源，没有替换原角色模型预制体，也没有修改已有地图。默认尺寸与孙悟空的角色碰撞体相匹配。

## 参数与动画

- 移动速度：根对象 `NavMeshAgent / Speed`，默认 `5`。
- 相机：根对象 `ClickMoveCameraBinder` 自动查找主相机；有多台相机时，可在场景实例的 `Scene Camera` 手动指定。若相机没有原跟随目标，则使用 `Fallback Offset`。
- 动画：子对象的 `Animator` 已绑定本角色的 `BaiGuJing_Locomotion` 或 `TangSeng_Locomotion` 控制器，资源在相邻的 `Animations` 目录。
- `NavMeshLocomotionAnimator` 根据实际移动速度设置 `IsMoving` 和 `WalkSpeed`，无需自己调用播放函数。保持 `Apply Root Motion` 关闭，位置由寻路组件驱动。
- 替换动作：在对应控制器中，将 `Idle` / `Walk` 状态的 Motion 换成兼容 Humanoid 骨骼的循环动画，保留上述参数和状态转换即可。当前走路动作复用工程已有的人形动画，待机是简单呼吸循环。

如果点击无反应，先确认角色位于已烘焙/已加载的 NavMesh 上、地面有 Collider，并且没有点在 UI 上；地图若有 `PolygonWalkableArea`，目标还需要在其允许区域内。
