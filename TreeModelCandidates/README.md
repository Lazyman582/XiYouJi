# 山林树模型候选

以下预览图来自模型作者/平台的公开预览，仅用于选型。4 个候选均为 Poly Haven 的 CC0 资源，可用于商业项目并允许修改。

## 1. Pine Tree 01

- 适合：山地森林的高大主树、远近景骨架
- 特点：三种高大松树，枝层清晰，树干和树皮细节最好
- 官方页面：https://polyhaven.com/a/pine_tree_01
- 许可：CC0

## 2. Pine Sapling Medium

- 适合：中景松树、林缘和坡地过渡
- 特点：三种中型松树，枝叶更稀疏，组合后层次自然
- 官方页面：https://polyhaven.com/a/pine_sapling_medium
- 许可：CC0

## 3. Pine Sapling Small

- 适合：近景补充树、幼树和低矮林层
- 特点：三种小型松树，适合与 1 号或 2 号混合摆放
- 官方页面：https://polyhaven.com/a/pine_sapling_small
- 许可：CC0

## 4. Tree Small 02

- 适合：山林中的阔叶混合树，打破纯松林的重复感
- 特点：枝叶更密，适合做少量视觉焦点或混合林
- 官方页面：https://polyhaven.com/a/tree_small_02
- 许可：CC0

建议优先考虑“1 + 2 + 3”组成纯松林；如果想要更接近真实山林，选择“1 + 2 + 3 + 4”混合。你回复编号后，我再导入对应模型并替换项目树材质。
